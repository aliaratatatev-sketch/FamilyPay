# 🤖 AI Features в FamilyPay

## Обзор
FamilyPay интегрирован с локальной AI-моделью **Ollama Mistral 7B** для предоставления персонализированных рекомендаций и помощи пользователям.

## Установленная модель
- **Модель**: `mistral:latest`
- **Размер**: 4.4 GB (ID: 6577803aa9a0)
- **URL**: http://localhost:11434
- **Статус**: Запущен (Process ID: 28772)

---

## 1. AI-Чат Ассистент
**Страница**: `/dashboard/ai-assistant`  
**API**: `POST /api/ai/chat`

### Функционал
- Полноценный чат с историей последних 6 сообщений
- Ролевые системные промпты:
  - **PARENT**: аналитический подход, советы по бюджету
  - **TEEN/VIEWER**: простой язык, советы по накоплениям
- Быстрые промпты для родителей и детей
- Fallback на правила, если Ollama недоступен

### Системный промпт (ключевые правила)
```
- НИКОГДА не упоминай: банки, субсидии, документы, справки, инвестиции
- Это домашний семейный бюджет в сомах (KGS)
- Отвечай в 2-4 предложениях
- Дружелюбный тон, простые слова
```

### Пример запроса
```typescript
POST /api/ai/chat
{
  "message": "Можно мне 5000 сом на донаты?",
  "context": { /* последние 6 сообщений */ }
}
```

## 2. AI-Рекомендации для родителей
**Страница**: `/dashboard/manage-requests`  
**API**: `POST /api/ai/analyze-request`

### Функционал
- Анализ pending запросов от детей
- Рекомендация: одобрить полностью / частично / отклонить
- Отображается в виде фиолетовой карточки "💡 AI-Совет родителю"
- Учитывает баланс семьи, категорию, историю трат

### Пример ответа
```
"10% от баланса. Рекомендуем одобрить частично (2000 сом). 
Предложите ребёнку сэкономить часть на будущее."
```

### Параметры
- Temperature: **0.5** (структурированные рекомендации)
- Max tokens: 150

---

## 3. AI-Оценка запроса для детей
**Страница**: `/dashboard/money-requests` (модалка создания)  
**API**: `POST /api/ai/evaluate-request`

### Функционал
- Автоматическая оценка при вводе суммы и описания
- Debounce 1 секунда (избегает лишних запросов)
- Возвращает JSON:
  - `category`: предположительная категория
  - `approvalChance`: "Высокий" / "Средний" / "Низкий"
  - `reason`: краткая причина оценки

### Пример ответа
```json
{
  "category": "Игры",
  "approvalChance": "Средний",
  "reason": "Сумма умеренная, но нужно объяснить родителям пользу."
}
```

### Параметры
- Temperature: **0.3** (точный JSON)
- Max tokens: 100

---

## 4. AI-Инсайт дня (Dashboard)
**Страница**: `/dashboard` (главная)  
**API**: `POST /api/ai/daily-insight`

### Функционал
- Генерируется при загрузке dashboard
- Учитывает:
  - Общий баланс семьи
  - Траты за месяц и их изменение
  - Количество pending запросов
  - Топ категория трат
- Отображается в карточке AI-ассистента
- Краткий совет на день (2-3 предложения)

### Пример инсайта
```
"У вас 3 ожидающих запроса на 8500 сом. Траты в категории 
'Развлечения' выросли на 15%. Обсудите с семьёй приоритеты!"
```

### Параметры
- Temperature: **0.7** (креативные инсайты)
- Max tokens: 120

## Общие принципы

### 🔐 Безопасность
- Все endpoints требуют авторизацию через NextAuth
- Проверка роли пользователя (PARENT/TEEN/CHILD)
- Валидация входных данных

### ⚡ Производительность
- Debounce для evaluate-request (1 секунда)
- Ограничение контекста чата (6 последних сообщений)
- Fallback на правила при недоступности Ollama

### 🌐 Локализация
- Все промпты на русском языке
- Валюта: KGS (сомы)
- Контекст: Кыргызстан, семейный бюджет

### 🎯 UX
- Индикаторы загрузки (spinner + "Генерирую...")
- Graceful fallback при ошибках
- Визуально выделенные AI-блоки (фиолетовый градиент)

## Как запустить

1. Убедитесь, что Ollama запущен:
```bash
ollama serve
```

2. Проверьте модель:
```bash
ollama list
# Должно показать: mistral:latest
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте http://localhost:3000/dashboard

## Тестирование

### Чат-ассистент
1. Зайдите в `/dashboard/ai-assistant`
2. Выберите Quick Prompt или введите свой вопрос
3. Проверьте, что ответ соответствует роли (PARENT/TEEN)

### Рекомендации родителям
1. Зайдите в `/dashboard/manage-requests`
2. Создайте pending запрос от имени ребенка
3. Под запросом появится "💡 AI-Совет родителю"

### Оценка для детей
1. Зайдите в `/dashboard/money-requests`
2. Нажмите "Создать новый запрос"
3. Введите сумму и описание → появится оценка через 1 секунду

### Инсайт дня
1. Откройте `/dashboard`
2. В карточке AI-ассистента должен загрузиться инсайт
3. Если Ollama недоступен → фоллбэк текст

## Troubleshooting

### Ollama не отвечает
```bash
# Перезапустите Ollama
ollama serve
```

### Модель не найдена
```bash
# Скачайте mistral
ollama pull mistral:latest
```

### AI возвращает fallback
- Проверьте URL: `http://localhost:11434`
- Проверьте процесс: `Get-Process ollama`
- Проверьте логи: `console.error` в браузере

### Слишком длинные ответы
- Снизьте `max_tokens` в соответствующем API
- Увеличьте строгость в системном промпте
