## 🔒 Безопасность

### Реализованные меры:

1. **Email Whitelist** ✅
   - Только указанные email могут получить доступ
   - Проверка на уровне API и middleware

2. **Временные коды** ✅
   - Код действителен 5 минут
   - Автоматическая очистка истекших кодов

3. **Одноразовые коды** ✅
   - Каждый код используется только один раз
   - Удаление после успешной верификации

4. **HttpOnly Cookies** ✅
   - Токен доступа хранится в защищенных cookies
   - Защита от XSS атак

5. **Middleware Protection** ✅
   - Проверка на уровне Next.js middleware
   - Защита всех `/admin/*` routes

6. **Обязательная 2FA** ✅
   - Код требуется при каждом входе в админ-панель
   - Нет возможности обойти верификацию

## 🎯 User Flow

### Для администратора:

```
1. Вход в аккаунт (Google OAuth / Email+Password)
   ↓
2. Dashboard с кнопкой "🔐 Админ-панель"
   ↓
3. Клик на кнопку
   ↓
4. Открывается модальное окно
   ↓
5. Автоматическая отправка кода в Telegram
   ↓
6. Администратор получает код в Telegram
   ↓
7. Ввод кода в форму
   ↓
8. Проверка кода на сервере
   ↓
9. Установка cookie с токеном доступа
   ↓
10. Redirect в админ-панель (/admin)
   ↓
11. Middleware проверяет токен
   ↓
12. Доступ к админ-панели ✅
```

### Для обычного пользователя:

```
1. Вход в аккаунт
   ↓
2. Dashboard БЕЗ кнопки "Админ-панель"
   ↓
3. Работа с функционалом обычного пользователя
```
