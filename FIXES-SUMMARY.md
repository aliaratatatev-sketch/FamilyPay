# Исправления от 09.01.2026

## 1. ✅ Исправлена проблема с двумя логотипами
- Удалены дублирующиеся headers со всех dashboard страниц
- Теперь используется единый header из layout.tsx
- Логотип "FP FamilyPay" отображается корректно

## 2. ✅ Показываются все запросы (а не только 1)
**Проблема**: На странице управления запросами показывался только 1 запрос вместо всех 3

**Решение**: 
- Удален фильтр `requesterId` из запроса на странице `/dashboard/manage-requests`
- Теперь родители и админы видят ВСЕ запросы семьи, а не только свои

## 3. ✅ Кнопки "Одобрить", "Отложить", "Отклонить"
**Где искать**: Страница `/dashboard/manage-requests` (для родителей/админов)

**НЕ путать с**: `/dashboard/money-requests` (страница для детей/подростков)

**Дизайн кнопок**:
- "Одобрить" - зеленая кнопка (#0D6D6E)
- "Отложить" - белая кнопка с рамкой
- "Отклонить" - текстовая ссылка (серый текст)

Кнопки отображаются только для запросов со статусом PENDING.

## 4. ✅ Уведомления теперь работают с навигацией

**Изменения**:
- При клике на уведомление происходит переход на соответствующую страницу
- Для "Новый запрос на деньги" → переход на `/dashboard/manage-requests?requestId=...`
- Для "Запрос одобрен/отклонен" → переход на `/dashboard/money-requests?requestId=...`
- Автоматический скролл к конкретному запросу
- Временная подсветка (2 сек) целевого запроса

**Типы навигации**:
- `MONEY_REQUEST` → `/dashboard/manage-requests` (с requestId)
- `REQUEST_APPROVED/REJECTED` → `/dashboard/money-requests` (с requestId)
- `BUDGET_ALERT` → `/dashboard/budgets`
- `GOAL_*` → `/dashboard/goals` (с id)
- `FAMILY_INVITE` → `/dashboard/family`
- `LOW_BALANCE/LARGE_EXPENSE` → `/dashboard/accounts`

## Как проверить:

### Проверка 1: Логотип
1. Откройте любую dashboard страницу
2. Убедитесь что логотип "FP FamilyPay" отображается только один раз вверху

### Проверка 2: Все запросы видны
1. Войдите как родитель/админ
2. Перейдите на `/dashboard/manage-requests`
3. Должны видеть ВСЕ запросы семьи (не только свои)

### Проверка 3: Кнопки управления
1. Войдите как родитель/админ
2. Перейдите на `/dashboard/manage-requests`
3. Для каждого PENDING запроса должны быть видны кнопки:
   - Одобрить (зеленая)
   - Отложить (белая с рамкой)
   - Отклонить (текстовая ссылка)

### Проверка 4: Навигация из уведомлений
1. Создайте новый запрос на деньги
2. Войдите как родитель
3. Кликните на колокольчик уведомлений
4. Кликните на уведомление "Новый запрос на деньги"
5. Должен произойти переход на страницу управления запросами
6. Страница автоматически прокрутится к этому запросу с подсветкой

## Важно!

### Две разные страницы:
1. `/dashboard/money-requests` - Для ДЕТЕЙ (создание и просмотр своих запросов)
2. `/dashboard/manage-requests` - Для РОДИТЕЛЕЙ (управление всеми запросами семьи)

Не путайте эти страницы при тестировании!
