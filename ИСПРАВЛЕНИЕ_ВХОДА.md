# Исправление проблемы входа через Google

## Что было сделано:

Внесены изменения в файлы для исправления проблемы с возвратом на страницу входа после выбора аккаунта Google.

### 1. Изменения в `lib/auth.ts`

**Исправлено:**
- Улучшен callback `redirect` - теперь использует `baseUrl` от NextAuth вместо переменной окружения
- Это позволяет NextAuth автоматически определять правильный URL (localhost для разработки, ваш домен Vercel для продакшена)
- Добавлено лучшее логирование для отладки

**Исправлено:**
- Callback `signIn` теперь более явно обрабатывает вход через Google
- PrismaAdapter автоматически создаст пользователя в БД при первом входе через Google

### 2. Изменения в `app/login/page.tsx`

**Исправлено:**
- Функция `handleGoogleSignIn` теперь правильно передает `callbackUrl` и `redirect: true`
- Это заставляет NextAuth автоматически перенаправлять после успешного входа

## Что нужно сделать на Vercel:

### Шаг 1: Проверьте переменные окружения

Зайдите на Vercel Dashboard → Ваш проект → Settings → Environment Variables

**Обязательно должны быть установлены (для Production):**

```
NEXTAUTH_URL=https://family-pay-ashy.vercel.app
NEXTAUTH_SECRET=your-super-secret-key-change-this-in-production
GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret
```

⚠️ Замените значения на ваши реальные ключи из файла `.env`

⚠️ **ВАЖНО**: Замените `https://family-pay-ashy.vercel.app` на ваш актуальный URL Vercel, если он отличается!

### Шаг 2: Проверьте Google Cloud Console

1. Откройте: https://console.cloud.google.com/apis/credentials
2. Выберите ваш OAuth 2.0 Client ID
3. В **Authorized redirect URIs** должно быть:
   ```
   https://family-pay-ashy.vercel.app/api/auth/callback/google
   ```
4. Если этого URL нет - добавьте его и сохраните!

### Шаг 3: Задеплойте изменения на Vercel

**Вариант A: Через Git (рекомендуется)**
```bash
git add .
git commit -m "Fix Google OAuth redirect issue"
git push
```
Vercel автоматически задеплоит изменения.

**Вариант B: Вручную через Vercel Dashboard**
1. Deployments → последний деплой → три точки → Redeploy
2. Нажмите Redeploy

### Шаг 4: Проверьте работу

1. Откройте ваш сайт: https://family-pay-ashy.vercel.app
2. Нажмите "Войти через Google"
3. Выберите аккаунт
4. Вы должны попасть на `/dashboard`

## Если проблема осталась:

### Проверьте логи на Vercel:

1. Зайдите в Vercel Dashboard → Deployments → последний деплой
2. Нажмите на деплой → View Function Logs
3. Попробуйте войти через Google
4. В логах должны появиться сообщения:
   ```
   ✅ SignIn callback triggered
   🔄 Redirect callback triggered
   📝 Session callback triggered
   ```

Если видите `❌` или ошибки - скопируйте их и отправьте разработчику.

### Возможные ошибки:

1. **redirect_uri_mismatch** 
   → Проверьте Authorized redirect URIs в Google Console
   
2. **Возвращает на /login** 
   → Проверьте NEXTAUTH_URL на Vercel
   → Убедитесь, что она совпадает с URL вашего сайта
   
3. **AccessDenied**
   → Проверьте, что ваш email разрешен для входа
   → Возможно, нужно добавить email в белый список

## Локальное тестирование:

Если хотите протестировать локально:

1. Убедитесь, что в `.env`:
   ```
   NEXTAUTH_URL="http://localhost:3000"
   ```

2. В Google Console добавьте redirect URI:
   ```
   http://localhost:3000/api/auth/callback/google
   ```

3. Запустите проект:
   ```bash
   npm run dev
   ```

4. Откройте http://localhost:3000/login и проверьте вход
