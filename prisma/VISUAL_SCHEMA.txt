║                         ИНДЕКСЫ (для производительности)                   ║
╚════════════════════════════════════════════════════════════════════════════╝

Transaction:
  ⚡ (familyId, date)         ← Быстрая выборка транзакций по периоду
  ⚡ (accountId)               ← История счёта
  ⚡ (categoryId)              ← Отчёты по категориям
  ⚡ (userId)                  ← Персональная история

Budget:
  ⚡ (familyId, startDate, endDate)  ← Активные бюджеты

Goal:
  ⚡ (familyId, status)        ← Активные цели

Notification:
  ⚡ (userId, isRead)          ← Непрочитанные уведомления

ActivityLog:
  ⚡ (userId, createdAt)       ← История действий

RecurringTransaction:
  ⚡ (familyId, nextDate)      ← Предстоящие транзакции

╔════════════════════════════════════════════════════════════════════════════╗
║                      ОСНОВНЫЕ ПОТОКИ ДАННЫХ                                ║
╚════════════════════════════════════════════════════════════════════════════╝

1. СОЗДАНИЕ ТРАНЗАКЦИИ:
   User → Transaction → FinancialAccount (обновление balance)
                     → Budget (обновление spent)
                     → ActivityLog (запись действия)

2. СОЗДАНИЕ БЮДЖЕТА:
   User → Budget ← Category
                → Периодическая проверка на превышение
                → Notification (при достижении порога)

3. СОЗДАНИЕ ЦЕЛИ:
   User → Goal → GoalAllocation ← FinancialAccount
              → Периодический расчёт прогресса
              → Notification (при достижении вехи)

4. ПОВТОРЯЮЩИЕСЯ ТРАНЗАКЦИИ:
   RecurringTransaction → (по расписанию) → Transaction (автосоздание)
                                          → Notification (напоминание)
