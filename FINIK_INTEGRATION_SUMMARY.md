## 🚀 Как использовать:

### Шаг 1: Настроить credentials
1. Получите API ключ и Account ID в личном кабинете Finik
2. Обновите `.env` файл:
   ```env
   FINIK_API_KEY="ваш-реальный-api-key"
   FINIK_ACCOUNT_ID="ваш-реальный-account-id"
   ```

### Шаг 2: Запустить сервер
```bash
npm run dev
```

### Шаг 3: Тестировать оплату
1. Откройте http://localhost:3000
2. Перейдите в секцию "Pricing"
3. Нажмите кнопку "Оплатить" на любом тарифе (кроме Enterprise)
4. Вы будете перенаправлены на форму оплаты Finik
5. Сумма платежа: **5 сомов** (жестко зафиксирована)

### Шаг 4: Проверить webhook (для продакшена)
Webhook URL: `http://ваш-домен.com/api/finik/webhook`

## 📊 Процесс оплаты:

1. Пользователь нажимает "Оплатить" на лендинге
2. Проверяется авторизация
3. Создается платеж на 5 сом через `/api/finik/create-payment`
4. Пользователь перенаправляется на форму Finik Pay
5. Пользователь сканирует QR-код и оплачивает
6. Finik отправляет webhook на `/api/finik/webhook`
7. Webhook верифицируется и обрабатывается
8. Пользователь возвращается на сайт с уведомлением об успехе
