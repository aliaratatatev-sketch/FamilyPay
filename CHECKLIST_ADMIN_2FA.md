# ✅ Чеклист настройки 2FA для админ-панели

## Первоначальная настройка

### ☐ 1. Создание Telegram бота

- [ ] Открыть [@BotFather](https://t.me/BotFather) в Telegram
- [ ] Отправить команду `/newbot`
- [ ] Придумать имя бота (например, "FamilyPay Admin")
- [ ] Придумать username (например, "familypay_admin_bot")
- [ ] Скопировать и сохранить токен бота
- [ ] Запустить бота (нажать Start или отправить /start)
- [ ] Отправить боту любое сообщение (например, "Привет")

### ☐ 2. Получение Chat ID

**Вариант A: Через скрипт (рекомендуется)**
- [ ] Добавить `TELEGRAM_BOT_TOKEN` в `.env`
- [ ] Запустить: `npm run telegram:get-id`
- [ ] Скопировать Chat ID из вывода

**Вариант B: Вручную**
- [ ] Открыть в браузере: `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
- [ ] Найти `"chat":{"id":123456789}`
- [ ] Скопировать Chat ID

### ☐ 3. Настройка .env

- [ ] Открыть файл `.env`
- [ ] Добавить/обновить:
  ```env
  TELEGRAM_BOT_TOKEN="ваш-токен-от-BotFather"
  TELEGRAM_CHAT_ID="ваш-chat-id"
  ```
- [ ] Сохранить файл

### ☐ 4. Добавление администраторов

- [ ] Открыть `lib/admin-config.ts`
- [ ] Добавить email в массив `ADMIN_EMAILS`:
  ```typescript
  export const ADMIN_EMAILS = [
    'aliaratatatev@gmail.com',
    'your-email@gmail.com',  // ← Ваш email
  ];
  ```
- [ ] Открыть `middleware.ts`
- [ ] Добавить тот же email в массив `ADMIN_EMAILS`:
  ```typescript
  const ADMIN_EMAILS = [
    'aliaratatatev@gmail.com',
    'your-email@gmail.com',  // ← Ваш email
  ];
  ```
- [ ] Сохранить оба файла

### ☐ 5. Тестирование бота

- [ ] Запустить: `npm run telegram:test`
- [ ] Убедиться, что все проверки прошли успешно
- [ ] Проверить, что тестовое сообщение пришло в Telegram

### ☐ 6. Проверка работы

- [ ] Запустить проект: `npm run dev`
- [ ] Войти в аккаунт с email администратора
- [ ] Убедиться, что кнопка "🔐 Админ-панель" видна на Dashboard
- [ ] Нажать на кнопку
- [ ] Проверить, что модальное окно открылось
- [ ] Проверить, что код пришел в Telegram
- [ ] Ввести код в форму
- [ ] Убедиться, что вход в админ-панель успешен

## Troubleshooting

### ❌ Код не приходит в Telegram

- [ ] Проверить `TELEGRAM_BOT_TOKEN` в `.env`
- [ ] Проверить `TELEGRAM_CHAT_ID` в `.env`
- [ ] Убедиться, что бот запущен (/start)
- [ ] Запустить `npm run telegram:test` для диагностики
- [ ] Проверить логи сервера на наличие ошибок

### ❌ "Access denied"

- [ ] Проверить, что ваш email есть в `lib/admin-config.ts`
- [ ] Проверить, что ваш email есть в `middleware.ts`
- [ ] Убедиться, что email написан **точно так же** (регистр важен!)
- [ ] Перезапустить сервер после изменений
- [ ] Выйти и войти заново

### ❌ "Invalid code"

- [ ] Проверить, что код введен правильно (6 цифр)
- [ ] Убедиться, что код не истек (5 минут)
- [ ] Запросить новый код кнопкой "Отправить новый код"
- [ ] Проверить время на сервере (может быть расхождение)

### ❌ Кнопка "Админ-панель" не видна

- [ ] Убедиться, что вы вошли в аккаунт
- [ ] Проверить, что ваш email в `ADMIN_EMAILS`
- [ ] Очистить кэш браузера (Ctrl+Shift+R)
- [ ] Проверить консоль браузера на ошибки
- [ ] Перезапустить сервер

### ❌ Redirect на /dashboard при входе в /admin

- [ ] Удалить cookie `admin_access_token` в DevTools
- [ ] Пройти верификацию заново
- [ ] Проверить, что middleware.ts не содержит ошибок
