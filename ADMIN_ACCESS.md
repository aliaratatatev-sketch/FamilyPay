# Доступ к админ-панели с 2FA через Telegram

## Описание

Система двухфакторной аутентификации для доступа к админ-панели через Telegram бот. При каждом входе в админ-панель администратору отправляется 6-значный код в Telegram.

## Особенности

- 🔐 **Двухфакторная аутентификация** — код отправляется в Telegram при каждом входе
- 📧 **Контроль по email** — только указанные email-адреса могут получить доступ
- ⏰ **Ограниченное время** — код действителен 5 минут
- 🔄 **Обязательная верификация** — требуется код при каждом входе в админ-панель
- 🚪 **Раздельный выход** — можно выйти из админ-панели без выхода из аккаунта

## Настройка Telegram бота

### 1. Создание бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Введите имя бота (например, "FamilyPay Admin")
4. Введите username бота (должен заканчиваться на "bot", например, "familypay_admin_bot")
5. Сохраните токен, который выдаст BotFather

### 2. Получение Chat ID

#### Способ 1: С помощью скрипта

1. Добавьте токен в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN="your-bot-token-here"
   ```

2. Запустите бота в Telegram и отправьте ему любое сообщение

3. Запустите скрипт:
   ```bash
   node scripts/get-telegram-chat-id.js
   ```

4. Скопируйте ваш Chat ID

#### Способ 2: Вручную

1. Запустите бота и отправьте ему сообщение
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
3. Найдите поле `"chat":{"id":123456789}` — это ваш Chat ID

### 3. Настройка переменных окружения

Добавьте в файл `.env`:

```env
# Telegram Bot для 2FA
TELEGRAM_BOT_TOKEN="8953644253:AAFqXcAxU5bj02AUMEu0dtguOspcc4ADmMw"
TELEGRAM_CHAT_ID="6956101864"
```

## Использование

### Вход в админ-панель

1. Войдите в свой аккаунт на сайте
2. На странице Dashboard справа вверху появится кнопка **"🔐 Админ-панель"** (только для админов)
3. Нажмите на кнопку
4. Откроется модальное окно с запросом кода
5. Код автоматически отправится в ваш Telegram
6. Введите 6-значный код в форму
7. После успешной верификации вы попадете в админ-панель

### Работа с кодом

- ⏰ Код действителен **5 минут**
- 🔄 Можно запросить новый код через **1 минуту** после предыдущего
- 🔢 Код состоит из **6 цифр**
- 📱 Код отправляется в Telegram с информацией о email

### Выход из админ-панели

В админ-панели в левом меню внизу есть две кнопки:

1. **🚪 Выйти из админ-панели** — возврат в Dashboard (остаетесь авторизованным)
2. **Выйти** — полный выход из аккаунта

При следующем входе в админ-панель потребуется новый код.

## Безопасность

### Реализованные меры

1. **Email whitelist** — только указанные email могут запросить код
2. **Ограничение по времени** — код действителен 5 минут
3. **Одноразовые коды** — каждый код используется только один раз
4. **HttpOnly cookies** — токен доступа хранится в защищенных cookies
5. **Middleware защита** — доступ к `/admin/*` проверяется на уровне middleware
6. **Обязательная верификация** — требуется код при каждом входе

### Рекомендации

- 🔐 Не делитесь токеном бота с посторонними
- 📧 Регулярно проверяйте список администраторов
- 🔄 Периодически обновляйте токен бота
- 📱 Включите 2FA для вашего Telegram аккаунта
- 🚨 Мониторьте логи входов в админ-панель

## API Endpoints

### POST `/api/admin/request-access`

Запрос кода доступа к админ-панели.

**Требования:**
- Пользователь должен быть авторизован
- Email должен быть в списке ADMIN_EMAILS

**Ответ:**
```json
{
  "success": true,
  "message": "Код отправлен в Telegram",
  "expiresIn": 300
}
```

### POST `/api/admin/verify-access`

Проверка кода доступа.

**Параметры:**
```json
{
  "code": "123456"
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "Access granted",
  "accessToken": "...",
  "expiresIn": 86400
}
```

### GET `/api/admin/check-access`

Проверка текущего доступа к админ-панели.

**Ответ:**
```json
{
  "hasAccess": true,
  "isAdmin": true
}
```

### POST `/api/admin/logout-admin`

Выход из админ-панели (удаление токена доступа).

**Ответ:**
```json
{
  "success": true,
  "message": "Logged out from admin panel"
}
```

## Troubleshooting

### Код не приходит в Telegram

1. Проверьте правильность TELEGRAM_BOT_TOKEN
2. Проверьте правильность TELEGRAM_CHAT_ID
3. Убедитесь, что бот запущен (отправьте /start)
4. Проверьте логи сервера на наличие ошибок

### "Access denied"

1. Убедитесь, что ваш email есть в ADMIN_EMAILS
2. Проверьте регистр (email должен совпадать точно)
3. Проверьте, что вы авторизованы в системе

### "Invalid code"

1. Убедитесь, что код правильный (6 цифр)
2. Проверьте, не истек ли срок действия кода (5 минут)
3. Запросите новый код

### Redirect на /dashboard при попытке зайти в /admin

1. Код либо не был введен, либо истек
2. Cookie "admin_access_token" отсутствует или невалидна
3. Пройдите верификацию заново через Dashboard

## Production рекомендации

В production окружении рекомендуется:

1. **Использовать Redis** для хранения кодов вместо in-memory Map
2. **Настроить rate limiting** для защиты от brute-force атак
3. **Включить HTTPS** для защиты cookies
4. **Логировать все попытки** доступа к админ-панели
5. **Настроить мониторинг** для отслеживания подозрительной активности
6. **Использовать защищенные каналы** для Telegram (проверка подлинности бота)
