## 🚀 Как использовать

### Разработка нового компонента

1. Откройте `RESPONSIVE-SNIPPET.md`
2. Копируйте нужный паттерн
3. Адаптируйте под задачу
4. Смотрите на примеры в `components/examples/`

### Тестирование

1. Запустите `npm run dev`
2. Отсканируйте QR-код
3. Откройте на телефоне
4. Проверьте на разных breakpoints

### Проверка перед релизом

1. Откройте `RESPONSIVE-CHECKLIST.md`
2. Пройдите по всем пунктам
3. Тестируйте на реальном устройстве
4. Проверьте dark mode
