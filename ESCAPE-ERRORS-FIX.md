# 🔧 Исправление Escape-ошибок в проекте

## 🐛 Проблема

Иногда при редактировании `.tsx` файлов могут появляться ошибки вида:
- `Unterminated template`
- `Expected unicode escape`
- `Parsing ecmascript source code failed`

Это происходит из-за неправильных escape-последовательностей:
- `\n` вместо реального переноса строки
- `` `n `` (обратная кавычка + n)
- `)`n` вместо `)`

## ✅ Автоматическое решение

### Способ 1: Запустить скрипт исправления

```bash
npm run fix:escape
```

Скрипт автоматически:
1. Найдёт все `.tsx` и `.ts` файлы в проекте
2. Проверит их на наличие escape-ошибок
3. Исправит найденные проблемы
4. Выведет отчёт о исправлениях

### Способ 2: Ручное исправление

Если нужно исправить конкретный файл:

1. Откройте файл с ошибкой
2. Найдите строку с `\n` или `` `n ``
3. Замените на обычный перенос строки (Enter)

**Пример:**

```tsx
// ❌ Неправильно:
return (\n    <>\n      <main>

// ✅ Правильно:
return (
    <>
      <main>
```

## 🔄 После исправления

После исправления ошибок необходимо:

### 1. Очистить кэш Next.js

```bash
# Windows PowerShell
Remove-Item -Recurse -Force .next

# Linux/Mac
rm -rf .next
```

### 2. Перезапустить dev сервер

```bash
npm run dev
```

### 3. Обновить браузер

Нажмите `Ctrl+Shift+R` (или `Cmd+Shift+R` на Mac) для жёсткой перезагрузки

## 🛡️ Предотвращение проблемы

### VS Code настройки

Добавьте в `.vscode/settings.json`:

```json
{
  "files.eol": "\n",
  "editor.formatOnSave": true,
  "prettier.endOfLine": "lf"
}
```

### ESLint правило

Добавьте в `eslint.config.js`:

```javascript
{
  rules: {
    'no-useless-escape': 'error'
  }
}
```

## 🔍 Что делает скрипт fix-escape-errors.js

Скрипт автоматически исправляет следующие паттерны:

1. **`return (\n`** → **`return (`**
   - Убирает `\n` после `return (`

2. **`` )`n ``** → **`)`**
   - Убирает обратную кавычку и `n`

3. **`` </>`n ``** → **`</>`**
   - Исправляет закрывающие теги

4. **`> \n <`** → **`>\n<`**
   - Заменяет escaped переносы на реальные

## 🚨 Если проблема повторяется

Если после всех действий ошибка не исчезает:

1. **Проверьте консоль браузера** (F12)
   - Может быть другая ошибка

2. **Проверьте файл вручную**
   ```bash
   # Откройте файл в редакторе
   code app/dashboard/transactions/page.tsx
   ```

3. **Проверьте импорты**
   - Убедитесь, что все импорты правильные

4. **Создайте issue**
   - Опишите проблему
   - Приложите скриншот ошибки
   - Укажите какой файл
