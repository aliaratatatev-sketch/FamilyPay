# 📱 Быстрый старт: Тестирование на мобильных

## Шаг 1: Запустите сервер

```bash
npm run dev
```

В терминале появится что-то вроде:

```
╔═══════════════════════════════════════╗
║  🚀 FamilyPay Development Server     ║
╚═══════════════════════════════════════╝

📱 Local:    http://localhost:3000
📱 Network:  http://192.168.1.7:3000

📱 Scan QR code to open on mobile:

[QR-КОД ЗДЕСЬ]

═══════════════════════════════════════
```

## Шаг 2: Отсканируйте QR-код

1. Откройте камеру на телефоне (iPhone/Android)
2. Наведите на QR-код в терминале
3. Нажмите на появившееся уведомление
4. Приложение откроется в браузере!

## Шаг 3: Начните тестирование

✅ Теперь любые изменения в коде будут автоматически отображаться на телефоне (Hot Reload)

## Альтернатива: Ручной ввод

Если QR-код не работает, введите адрес вручную:

```
http://192.168.1.7:3000
```

(замените IP на тот, что показан в вашем терминале)

## Troubleshooting

### QR-код не появляется
```bash
# Показать QR-код отдельно
npm run qr
```

### Телефон не может подключиться

1. **Проверьте WiFi**: Оба устройства должны быть в одной сети
2. **Файрвол Windows**: Разрешите Node.js в файрволе
   ```powershell
   # Запустите PowerShell от администратора
   New-NetFirewallRule -DisplayName "Node.js Server" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
   ```
3. **Попробуйте другой порт**: Если 3000 занят
   ```bash
   PORT=3001 npm run dev
   ```

### Медленная загрузка

Это нормально для dev режима! В production будет быстрее.

## Полезные команды

```bash
# Обычный dev сервер с QR-кодом
npm run dev

# Без QR-кода (старый режим)
npm run dev:clean

# Только показать QR-код
npm run qr
```
