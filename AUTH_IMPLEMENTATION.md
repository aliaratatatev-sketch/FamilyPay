# Реализация авторизации и регистрации с Google OAuth

## ✅ Что было реализовано

### 1. Страница входа/регистрации (`/login`)
- **Переключатель режимов**: Пользователь может переключаться между "Войти" и "Регистрация" без перехода на другую страницу
- **Форма входа**: Email и пароль
- **Форма регистрации**: Имя, email и пароль
- **Google OAuth**: Кнопка "Войти через Google" с фирменной иконкой Google
- **Адаптивный дизайн**: Полностью соответствует стилю FamilyPay с градиентами и анимациями
- **Мультиязычность**: Поддержка русского, кыргызского и английского языков

### 2. Обновление Header
- Обе кнопки "Войти" и "Регистрация" теперь ведут на одну страницу `/login`
- Пользователь сам выбирает режим через переключатель

### 3. Backend интеграция
- **NextAuth.js v5 (beta)**: Современная система аутентификации
- **Google OAuth Provider**: Настроен и готов к использованию
- **Credentials Provider**: Вход по email/паролю с bcrypt хешированием
- **API роуты**:
  - `/api/auth/[...nextauth]` - обработчик NextAuth
  - `/api/auth/register` - регистрация новых пользователей

### 4. База данных
- Обновлена Prisma схема:
  - Добавлен enum `UserRole` (USER, ADMIN)
  - Поле `password` теперь опциональное (для OAuth пользователей)
  - Поле `role` для разграничения прав доступа
- Миграция применена к Neon PostgreSQL

### 5. Безопасность
- **bcryptjs**: Хеширование паролей
- **JWT сессии**: Безопасное хранение сессий
- **TypeScript типизация**: Расширены типы NextAuth для работы с ролями

## 🔑 Переменные окружения

Добавьте в `.env`:

```env
# NextAuth
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-super-secret-key-change-this-in-production"

# Google OAuth (заполните после настройки)
GOOGLE_CLIENT_ID="ваш_google_client_id"
GOOGLE_CLIENT_SECRET="ваш_google_client_secret"
```

## 🚀 Как настроить Google OAuth

1. Следуйте инструкциям в файле `GOOGLE_OAUTH_SETUP.md`
2. Получите Client ID и Client Secret из Google Cloud Console
3. Добавьте их в `.env`
4. Перезапустите сервер

## 📝 Использование

### Регистрация через email
1. Откройте `/login`
2. Переключитесь на "Регистрация"
3. Заполните: имя, email, пароль
4. Нажмите "Зарегистрироваться"
5. Автоматический вход после регистрации

### Вход через email
1. Откройте `/login`
2. Переключатель должен быть на "Войти"
3. Введите email и пароль
4. Нажмите "Войти"

### Вход через Google
1. Откройте `/login`
2. Нажмите "Войти через Google"
3. Выберите Google аккаунт
4. Разрешите доступ
5. Автоматическое создание пользователя при первом входе
