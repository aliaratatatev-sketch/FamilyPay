# Исправление доступа к админ панели

## Проблема
При попытке войти в админ панель через кнопку в сайдбаре дашборда, пользователь перенаправлялся обратно на страницу дашборда.

## Причина
Middleware проверял наличие cookie `admin_access_token` при доступе к `/admin`, но этот токен устанавливался только после верификации через Telegram код. При простом переходе по ссылке токена не было, поэтому middleware перенаправлял обратно.

## Решение

### Внесенные изменения:

1. **components/dashboard/Sidebar.tsx**
   - Добавлен импорт `AdminAccessModal` и `useRouter`
   - Добавлено состояние `hasAdminAccess` для отслеживания наличия токена доступа
   - Добавлено состояние `showAdminModal` для отображения модального окна
   - Обновлена функция `checkAdminAccess()` для проверки как `isAdmin`, так и `hasAccess`
   - Добавлена функция `handleAdminClick()` для перехвата кликов на кнопку админ панели
   - Добавлена функция `handleAdminModalClose()` для обработки закрытия модального окна
   - Обновлен рендеринг навигации для использования `handleAdminClick`
   - Добавлено модальное окно `AdminAccessModal` в конец компонента

### Как это работает:

1. При попытке перейти в админ панель проверяется наличие `admin_access_token`
2. Если токена нет - открывается модальное окно верификации
3. Модальное окно автоматически отправляет код в Telegram
4. Пользователь вводит 6-значный код из Telegram
5. После успешной верификации устанавливается cookie `admin_access_token`
6. Модальное окно закрывается и пользователь перенаправляется в админ панель

## Проверка работы:

1. Откройте приложение и войдите под администраторским аккаунтом (aliaratatatev@gmail.com)
2. В сайдбаре нажмите на "Админ панель" (иконка щита)
3. Должно открыться модальное окно с запросом кода
4. Проверьте Telegram - должно прийти сообщение с 6-значным кодом
5. Введите код в модальное окно
6. После успешной верификации вы попадете в админ панель
