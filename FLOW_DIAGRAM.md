## 🔄 Lifecycle кода верификации

```
┌─────────────────────────────────────────────────────────────┐
│                  ЖИЗНЕННЫЙ ЦИКЛ КОДА                        │
└─────────────────────────────────────────────────────────────┘

1. СОЗДАНИЕ
   ├─ POST /api/admin/request-access
   ├─ generateVerificationCode() → "123456"
   ├─ expiresAt = Date.now() + 5 * 60 * 1000
   └─ Map.set(email, { code, expiresAt })

2. ОТПРАВКА
   ├─ sendAdminVerificationCode(email, code)
   ├─ Telegram Bot API → sendMessage
   └─ Пользователь получает код

3. ПРОВЕРКА
   ├─ POST /api/admin/verify-access { code }
   ├─ savedData = Map.get(email)
   ├─ if (savedData.expiresAt < Date.now()) → ИСТЕК
   ├─ if (savedData.code !== code) → НЕВЕРНЫЙ
   └─ if (match) → УСПЕХ

4. ИСПОЛЬЗОВАНИЕ (при успехе)
   ├─ Map.delete(email)
   ├─ generateAccessToken()
   ├─ cookie.set('admin_access_token', token)
   └─ ЗАВЕРШЕНИЕ

5. ИСТЕЧЕНИЕ (через 5 минут)
   ├─ if (expiresAt < Date.now())
   ├─ Map.delete(email)
   └─ ТРЕБУЕТСЯ НОВЫЙ КОД
```

## 📊 Диаграмма состояний

```
┌─────────────────────────────────────────────────────────────┐
│                   СОСТОЯНИЯ ДОСТУПА                         │
└─────────────────────────────────────────────────────────────┘

[1] НЕ АВТОРИЗОВАН
     │
     │ Вход через Google/Email
     ↓
[2] АВТОРИЗОВАН (обычный пользователь)
     │
     │ Email не в ADMIN_EMAILS
     │
     │ Работа в Dashboard
     │ (кнопка "Админ-панель" скрыта)
     

[1] НЕ АВТОРИЗОВАН
     │
     │ Вход через Google/Email
     ↓
[3] АВТОРИЗОВАН (администратор)
     │
     │ Email в ADMIN_EMAILS
     ↓
[4] DASHBOARD (кнопка "Админ-панель" видна)
     │
     │ Клик "Админ-панель"
     ↓
[5] ЗАПРОС КОДА
     │
     │ Код отправлен в Telegram
     ↓
[6] ОЖИДАНИЕ ВВОДА
     │
     ├─ Код неверный → [6] (повтор ввода)
     │
     ├─ Код истек → [5] (новый код)
     │
     └─ Код верный
         ↓
[7] ДОСТУП К АДМИН-ПАНЕЛИ ✅
     │
     ├─ Выход из админки → [4] (Dashboard)
     │
     └─ Полный выход → [1] (не авторизован)
```

## 🎯 Точки принятия решений

```
┌──────────────────────────────────────────────────────────┐
│            КЛЮЧЕВЫЕ ПРОВЕРКИ БЕЗОПАСНОСТИ                │
└──────────────────────────────────────────────────────────┘

1. ПРОВЕРКА СЕССИИ
   if (!session?.user?.email)
      → 401 Unauthorized

2. ПРОВЕРКА EMAIL WHITELIST
   if (!ADMIN_EMAILS.includes(email))
      → 403 Forbidden

3. ПРОВЕРКА СРОКА ДЕЙСТВИЯ КОДА
   if (code.expiresAt < Date.now())
      → 410 Gone (expired)

4. ПРОВЕРКА СООТВЕТСТВИЯ КОДА
   if (savedCode !== inputCode)
      → 400 Bad Request

5. ПРОВЕРКА ТОКЕНА ДОСТУПА (Middleware)
   if (!cookie.admin_access_token)
      → Redirect /dashboard

Все проверки должны пройти ✅ для доступа к админ-панели
```
