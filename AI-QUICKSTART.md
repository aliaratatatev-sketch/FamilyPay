# 🚀 AI Quick Start - FamilyPay

Быстрый старт для работы с AI-функциями в FamilyPay.

---

## ⚡ За 3 минуты

### 1. Убедись, что Ollama запущен
```bash
# Проверь процесс
Get-Process | Where-Object {$_.ProcessName -eq "ollama"}

# Если не запущен:
ollama serve
```

### 2. Проверь модель
```bash
ollama list
# Должно показать: mistral:latest
```

### 3. Запусти dev-сервер
```bash
npm run dev
```

### 4. Открой браузер
```
http://localhost:3000/dashboard
```

---

## 🎯 Где найти AI

### 1. Главная страница (`/dashboard`)
**Что увидишь**:
- Карточка "🤖 AI-Ассистент"
- Инсайт дня (загружается автоматически)
- Кнопка "Открыть чат с AI"

**Чтобы проверить**:
- Обнови страницу → инсайт должен загрузиться за 2-3 секунды
- Если Ollama выключен → увидишь fallback текст

---

### 2. AI-Чат (`/dashboard/ai-assistant`)
**Что увидишь**:
- Поле ввода сообщения
- Quick Prompts (быстрые вопросы)
- История чата

**Чтобы проверить**:
1. Нажми на Quick Prompt → получишь ответ за 1-2 секунды
2. Или введи свой вопрос про бюджет

**Примеры вопросов**:
- "Как распределить 50000 сом на месяц?"
- "Можно ли одобрить 3000 сом на игры?"
- "Как научить детей экономить?"

---

### 3. Управление запросами (`/dashboard/manage-requests`)
**Что увидишь**:
- Список pending запросов от детей
- Под каждым запросом: "💡 AI-Совет родителю"

**Чтобы проверить**:
1. Создай pending запрос (от имени ребенка)
2. Зайди в manage-requests
3. Под запросом появится AI-рекомендация

---

### 4. Создание запроса (`/dashboard/money-requests`)
**Что увидишь**:
- Кнопка "Создать новый запрос"
- В модалке: поля для суммы и описания
- AI-оценка появляется через 1 секунду после ввода

**Чтобы проверить**:
1. Нажми "Создать новый запрос"
2. Введи сумму (например, 5000)
3. Введи описание (например, "Хочу новый телефон")
4. Подожди 1 секунду → увидишь оценку:
   - Категория: "Электроника"
   - Шанс одобрения: "Средний"
   - Причина: "..."

## 🐛 Troubleshooting

### Проблема: "AI не отвечает"
**Решение**:
```bash
# 1. Проверь, запущен ли Ollama
Get-Process | Where-Object {$_.ProcessName -eq "ollama"}

# 2. Если нет - запусти
ollama serve

# 3. Проверь модель
ollama list

# 4. Если модели нет - скачай
ollama pull mistral:latest
```

### Проблема: "Loading не пропадает"
**Решение**:
1. Открой DevTools → Console
2. Найди ошибку (красный текст)
3. Если видишь "Failed to fetch" → проверь Ollama
4. Если видишь "401 Unauthorized" → перелогинься

### Проблема: "AI упоминает банки"
**Решение**:
1. Это баг в системном промпте
2. Открой `/app/api/ai/[соответствующий endpoint]/route.ts`
3. Усиль запрет в системном промпте:
   ```typescript
   const systemPrompt = `
   СТРОГО ЗАПРЕЩЕНО упоминать: банки, кредиты, 
   инвестиции, субсидии, справки, документы!
   ...
   `;
   ```

### Проблема: "Слишком длинный ответ"
**Решение**:
1. Открой соответствующий API route
2. Снизь `max_tokens`:
   ```typescript
   await sendOllamaMessage(systemPrompt, userPrompt, 0.7, 100); // было 200
   ```
3. Усиль ограничение в промпте:
   ```typescript
   "ВАЖНО: Отвечай СТРОГО в 2 предложениях!"
   ```

## 💡 Полезные советы

1. **Debounce работает только в evaluate-request**
   - В остальных фичах ответ приходит сразу

2. **Контекст чата ограничен 6 сообщениями**
   - Если нужно больше - измени в `/app/dashboard/ai-assistant/page.tsx`

3. **Fallback - это фича, не баг**
   - Он нужен для работы без Ollama

4. **Логи - твой друг**
   - Всегда смотри Console в DevTools
   - Ошибки помечены ❌

5. **Temperature влияет на креативность**
   - 0.3 = точный JSON
   - 0.5 = сбалансированные советы
   - 0.7 = креативный чат
