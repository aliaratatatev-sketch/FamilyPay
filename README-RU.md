## 🌟 Основные возможности

### 🤖 ИИ Финансовый Ассистент
- **Умный анализ расходов** - ИИ автоматически определяет категорию по описанию
- **Персональные рекомендации** - советы по оптимизации бюджета
- **Прогноз экономии** - расчет потенциальной экономии по категориям
- **Быстрый анализ** - мгновенная категоризация любого расхода

### 👨‍👩‍👧‍👦 Управление семьёй
- **Создание семей** - неограниченное количество семей
- **Добавление участников** - по Email или по ID (быстро)
- **Роли и права** - Администратор, Родитель, Подросток, Наблюдатель
- **Прозрачность** - все видят расходы и доходы семьи

### 💳 Финансовый учёт
- **Множество счетов** - наличные, карты, сбережения
- **Транзакции** - доходы, расходы, переводы между счетами
- **Категории** - гибкая система категоризации
- **Мультивалютность** - RUB, USD, EUR, KGS

### 📊 Аналитика и отчёты
- **Статистика в реальном времени** - текущий баланс, расходы за месяц
- **Бюджеты** - установка лимитов по категориям
- **Цели накоплений** - отслеживание прогресса
- **Визуализация** - графики и диаграммы

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- PostgreSQL 14+
- npm или yarn

### Установка

1. **Клонирование репозитория**
```bash
git clone https://github.com/your-username/familypay.git
cd familypay
```

2. **Установка зависимостей**
```bash
npm install
```

3. **Настройка окружения**
```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/familypay"
NEXTAUTH_SECRET="your-secret-key"
NEXTAUTH_URL="http://localhost:3000"
```

4. **Инициализация БД**
```bash
npx prisma generate
npx prisma db push
```

5. **Запуск приложения**
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере

## 📖 Использование

### 1. Регистрация и вход
- Зарегистрируйтесь с email и паролем
- Или войдите через Google

### 2. Создание семьи
- На дашборде нажмите "Создать семью"
- Введите название и выберите валюту
- Вы автоматически станете администратором

### 3. Добавление участников

#### Способ 1: По ID (быстро)
```
1. Участник копирует свой ID из профиля
2. Вы заходите в "Управление семьёй" → "Пригласить"
3. Выбираете "По ID" → вставляете ID → "Добавить"
```

#### Способ 2: По Email (через ссылку)
```
1. В "Управление семьёй" → "Пригласить"
2. Выбираете "По Email" → вводите email
3. Копируете ссылку-приглашение и отправляете
```

### 4. Использование ИИ-ассистента
```
1. Нажмите на баннер "ИИ Финансовый Ассистент"
2. Введите описание расхода: "купил продукты в магазине на 3000р"
3. ИИ определит категорию и даст рекомендацию
4. Для полного анализа нажмите "Запустить полный анализ"
```

## 🏗️ Архитектура

### Технологический стек

**Frontend:**
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- NextAuth.js

**Backend:**
- Next.js API Routes
- Prisma ORM
- PostgreSQL
- bcrypt для паролей

**AI/ML:**
- Ollama (опционально)
- Встроенная логика анализа

### Структура проекта
```
familypay/
├── app/                    # Next.js App Router
│   ├── api/               # API endpoints
│   ├── dashboard/         # Дашборд и страницы
│   ├── components/        # React компоненты
│   └── page.tsx          # Главная страница
├── lib/                   # Утилиты и хелперы
│   ├── prisma.ts         # Prisma клиент
│   ├── auth.ts           # NextAuth конфигурация
│   └── session.ts        # Сессия хелперы
├── prisma/               # Схема БД
│   └── schema.prisma
└── public/               # Статические файлы
```
