# 📱 Разработка с просмотром на мобильном устройстве

## Быстрый старт

1. **Запустите dev сервер:**
   ```bash
   npm run dev
   ```

2. **Отсканируйте QR-код** который появится в терминале

3. **Откройте на телефоне** - приложение автоматически откроется в браузере

## Требования

- 📱 Телефон и компьютер должны быть в **одной WiFi сети**
- 🔥 На Windows может потребоваться разрешить доступ в файрволе

## Альтернативные команды

```bash
# Запуск без QR-кода (обычный режим)
npm run dev:clean

# Показать только QR-код (если сервер уже запущен)
npm run qr
```

## Настройка файрволла Windows

Если телефон не может подключиться:

1. Откройте **Windows Defender Firewall**
2. Нажмите **Allow an app through firewall**
3. Найдите **Node.js** и разрешите для **Private networks**

Или выполните команду (от администратора):
```powershell
New-NetFirewallRule -DisplayName "Node.js Server" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow
```

## Troubleshooting

**QR-код не появляется:**
- Подождите пока Next.js полностью запустится
- Используйте `npm run qr` для повторного показа

**Телефон не может подключиться:**
- Убедитесь что оба устройства в одной WiFi сети
- Проверьте настройки файрволла
- Попробуйте использовать IP адрес напрямую (показан в консоли)

**Медленная загрузка:**
- Это нормально для dev режима
- Production сборка будет быстрее (`npm run build && npm run start`)
