# Инструкция по тестированию доступа к админ панели

## Шаг 1: Подготовка

1. Убедитесь, что dev сервер запущен:
   ```bash
   npm run dev
   ```
   Сервер должен быть доступен по адресу: http://localhost:3000

2. Откройте Telegram и проверьте, что вы можете получать сообщения от бота

## Шаг 2: Вход в систему

1. Откройте браузер и перейдите на http://localhost:3000
2. Войдите в систему под администраторским аккаунтом:
   - Email: `aliaratatatev@gmail.com`
   - Используйте существующий аккаунт или зарегистрируйтесь, если это необходимо

## Шаг 3: Переход в дашборд

1. После входа вы должны попасть на страницу дашборда
2. В левом сайдбаре (боковом меню) вы увидите список пунктов навигации

## Шаг 4: Тестирование доступа к админ панели

1. В самом низу списка навигации найдите пункт "Админ панель" с иконкой щита 🛡️
2. Кликните на этот пункт

### Ожидаемое поведение:

**Если у вас НЕТ активного токена доступа:**
- Должно открыться модальное окно с заголовком "Вход в админ-панель"
- В модальном окне будет показана форма для ввода 6-значного кода
- В Telegram должно прийти сообщение с кодом (проверьте чат с ботом)
- Под полем ввода кода будет отображаться таймер обратного отсчета (5 минут)

**Если у вас УЖЕ ЕСТЬ активный токен доступа:**
- Вы будете перенаправлены напрямую в админ панель
- Откроется страница `/admin` с панелью управления

## Шаг 5: Ввод кода верификации

1. Откройте Telegram и скопируйте 6-значный код из сообщения
2. Вставьте код в поле ввода в модальном окне
3. Нажмите кнопку "Подтвердить" или нажмите Enter

### Ожидаемое поведение:

**При правильном коде:**
- Модальное окно закроется
- Вы будете перенаправлены на страницу админ панели (`/admin`)
- В cookies будет установлен токен `admin_access_token` (срок действия 1 час)

**При неправильном коде:**
- Появится сообщение об ошибке красным цветом
- Вы можете попробовать ввести код снова
- Если код истек, нажмите "Отправить новый код"

## Шаг 6: Работа в админ панели

После успешного входа вы должны увидеть:
- Левый сайдбар с разделами админки:
  - Dashboard (статистика)
  - Users (пользователи)
  - Families (семьи)
  - Categories (категории)
  - Accounts (счета)
  - Transactions (транзакции)
  - Budgets (бюджеты)
  - Goals (цели)
- Верхнее меню с переключателем темы и языка
- В футере сайдбара - кнопки выхода

## Шаг 7: Выход из админ панели

В админ панели есть два варианта выхода:

1. **Выйти из админ-панели** - удаляет только токен доступа к админке, но оставляет вас в системе
   - Вы вернетесь в дашборд
   - При следующей попытке войти в админку нужно будет снова ввести код

2. **Полный выход** - выход из всей системы
   - Вы будете перенаправлены на страницу логина
   - Потребуется заново войти в систему

## Возможные проблемы и решения

### Проблема 1: Кнопка "Админ панель" не отображается
**Причина:** Ваш email не добавлен в список администраторов
**Решение:** Проверьте файл `lib/admin-config.ts` и убедитесь, что ваш email есть в массиве `ADMIN_EMAILS`

### Проблема 2: Код не приходит в Telegram
**Причина:** Неправильные настройки Telegram бота
**Решение:** 
- Проверьте `.env` файл:
  - `TELEGRAM_BOT_TOKEN` должен быть установлен
  - `TELEGRAM_CHAT_ID` должен соответствовать вашему ID в Telegram
- Убедитесь, что вы начали чат с ботом (отправили /start)

### Проблема 3: Код истекает слишком быстро
**Причина:** Таймаут по умолчанию составляет 5 минут
**Решение:** Можно изменить в `lib/admin-config.ts`:
```typescript
export const VERIFICATION_CODE_EXPIRY = 10 * 60 * 1000; // 10 минут
```

### Проблема 4: После ввода правильного кода показывает ошибку
**Причина:** Возможно, код уже использован или истек
**Решение:** 
- Нажмите "Отправить новый код"
- Проверьте консоль браузера на наличие ошибок
- Проверьте логи сервера

### Проблема 5: Перенаправляет обратно в дашборд после успешной верификации
**Причина:** Cookie не устанавливается или middleware не видит его
**Решение:**
- Проверьте, что в middleware.ts список администраторов совпадает с admin-config.ts
- Проверьте консоль браузера - должна быть установлена cookie `admin_access_token`
- Попробуйте очистить cookies и повторить попытку

## Дополнительная информация

### Время действия токенов:
- **Код верификации:** 5 минут
- **Токен доступа:** 1 час

### Логи для отладки:
Проверьте консоль браузера (F12 -> Console) и терминал сервера для просмотра логов.

Ключевые сообщения в консоли сервера:
- `✅ Verification code sent to ...` - код отправлен
- `🔐 Verify-access called for: ...` - начата верификация
- `✅ Admin access granted to ...` - доступ предоставлен
- `❌ ...` - различные ошибки

### Безопасность:
- Коды одноразовые - каждый код можно использовать только один раз
- Коды имеют ограниченный срок действия
- Токены доступа хранятся в httpOnly cookies (недоступны из JavaScript)
- После logout токены удаляются
