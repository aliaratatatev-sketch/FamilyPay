📋 СЦЕНАРИЙ ДЕМОНСТРАЦИИ
───────────────────────────────────────────────────────────

1️⃣ ИИ-АССИСТЕНТ (ГЛАВНОЕ!) - 3 минуты

   Действия:
   ✓ Открыть http://localhost:3000
   ✓ Войти в систему
   ✓ На дашборде увидеть ФИОЛЕТОВЫЙ БАННЕР "ИИ Финансовый Ассистент"
   ✓ Нажать на баннер
   
   Быстрый анализ:
   ✓ Ввести: "купил продукты в Пятёрочке на 2500 рублей"
   ✓ Нажать "Анализировать"
   ✓ ИИ покажет категорию и рекомендацию
   
   Полный анализ:
   ✓ Нажать "Запустить полный анализ"
   ✓ Показать:
     • Сводку за месяц
     • Анализ ИИ
     • 4 рекомендации с экономией

2️⃣ УПРАВЛЕНИЕ СЕМЬЁЙ - 1 минута

   ✓ Перейти в "Управление семьёй"
   ✓ Показать созданные семьи
   ✓ Нажать "Пригласить"
   ✓ Показать "По ID (быстро)" - мгновенное добавление

3️⃣ ПРОФИЛЬ С ID - 30 секунд

   ✓ Зайти в "Профиль"
   ✓ Показать User ID с кнопкой копирования
